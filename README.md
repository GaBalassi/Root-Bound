# ROOTBOUND

Action-platformer roguelite 2D in pixel art, sviluppato con Unity 6000.6.2f1 e URP 2D.

## Stato del progetto

Configurazione iniziale del progetto Unity: pipeline grafica 2D, pacchetti e impostazioni di input. Questa tappa non contiene ancora scene giocabili o sistemi di gioco.

## Apertura

Aggiungere questa cartella a Unity Hub e aprirla con Unity 6000.6.2f1. Attendere il completamento dell'importazione dei pacchetti.

## Versionamento

Versionare Assets, Packages, ProjectSettings e i relativi file .meta. Cache, log e build restano fuori da Git.
